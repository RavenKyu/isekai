# 약속한 동작마다 실패하는 변이를 확인한다

## What happened

- 종료 이벤트 테스트가 ignore 상태로 남아 실제 스모크·CI 입구에서는 실행되지 않았다.
- SDK fixture가 일부 안전 계약을 관찰하지 않아 구현을 제거하는 변이가 통과했다.

## Why

- 테스트 파일의 존재와 정상 실행 성공만으로 각 약속의 검증을 대신했다.

## Do this instead

- 사람이 실행하는 스크립트·CI 입구에서 필요한 테스트가 실제로 실행되는지 확인한다.
- 각 약속을 어기는 최소 변이를 넣어 검사가 실패하는지 확인하고 즉시 복구한다.
- 테스트 이름 필터나 fixture가 검증 누락을 숨기지 않는지 본다.
- 테스트가 관찰하지 못하는 성능·자원 해제 효과는 미측정·미검증 범위로 명시한다.
