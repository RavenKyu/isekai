# 파일 중복 열기를 막을 때 쓰기 경로도 함께 확인한다

## What happened
- Load를 같은 파일의 기존 창에 포커스를 주는 동작으로 바꾸면서 Write tileset이 열린 출력 PNG를 교체할 수 있는 경로를 빠뜨렸다. 그 뒤 Open result를 눌러도 오래된 이미지의 창에 포커스만 갔다.
- Save image as의 열린 파일 검사는 경로 별칭을 먼저 정규화하지 않았고, 저장 후 editor가 보관하는 경로도 Load와 같은 기준으로 맞추지 않았다.
## Why
- 파일을 여는 경로만 바뀐다고 보고, 같은 파일을 쓰거나 저장 결과를 다시 여는 경로와 UI 안내를 함께 추적하지 않았다.
## Do this instead
- 열린 파일을 경로로 재사용하게 바꿀 때 Load, 메모리 이미지 저장, 추출 출력, 결과 다시 열기와 관련 안내 문구를 함께 확인한다.
- 같은 파일인지 비교하는 기준은 공유 helper로 모으고, 기존 출력의 별칭은 비교 전에 정규화한다. 저장 성공 후 editor가 보유하는 경로도 이후 Load와 같은 기준을 쓴다.
- 두 editor가 같은 파일을 다룰 때와 symlink 별칭을 쓸 때, 거부된 쓰기가 PNG와 메타 바이트를 바꾸지 않는지 검사한다.
