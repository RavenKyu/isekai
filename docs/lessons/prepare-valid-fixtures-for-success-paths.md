# 성공 경로 테스트의 fixture 전제조건을 먼저 맞춘다

## What happened

- Save 성공 경로 검사에서 기존 fixture의 spacing을 늘렸더니 마지막 sprite가 격자 범위를 벗어나 저장 전에 실패했다.
- 이미 열린 파일의 덮어쓰기 방지 검사에서는 fixture PNG를 쓰기 전에 부모 디렉터리를 만들지 않아 준비 단계에서 실패했다.

## Why

- fixture를 단순한 이미지나 파일 경로로만 보고, 연결된 메타 범위와 디렉터리 존재 조건을 빠뜨렸다.

## Do this instead

- 성공 경로 검사에 쓸 변경을 정할 때 fixture의 sprite·clip 참조와 범위가 계속 유효한지 확인한다. 검증 실패 자체를 확인할 때는 별도 실패 경로로 둔다.
- 이미 존재하는 파일을 전제로 하는 검사는 부모 디렉터리와 파일 바이트를 먼저 준비한 뒤 보호 동작을 호출한다.
- 실패 위치가 준비 단계인지 검증하려는 동작인지 확인하고, 테스트를 통과시키려고 제품의 검증을 느슨하게 만들지 않는다.
